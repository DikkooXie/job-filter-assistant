# 个人画像与岗位筛选分开，不合并

个人画像只供 AI 计算匹配分，不隐藏岗位；岗位筛选由代码直接决定岗位是否出现在列表中，不经过 AI。两者的城市、薪资、排除类字段看起来重复，但它们一个负责软判断（分数），一个负责硬判断（显示与否），机制、成本和可预期性都不同。因此保留两个页面，只在界面上把分工讲清楚：画像统一说「分数」，筛选统一说「显示 / 不显示」。

## 考虑过的方案

- **合并成一个「求职目标」，每条规则自选「影响打分」或「隐藏岗位」**：2026-11-03 的设计评审提过这个方案，没有采用。合并会把「事实与偏好」和「过滤规则」混成一处，模糊掉「AI 判断」和「代码判断」的边界，还需要迁移已有设置。
- **在筛选字段旁显示画像值、提供「从画像带入」**：可以作为以后的新功能单独评审，不属于本决定的范围。
