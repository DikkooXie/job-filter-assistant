# Offercome

在 **BOSS直聘** 或 **前程无忧** 上翻岗位时，Offercome 会把你看到的岗位记下来，再按你的个人画像，用你自己配置的 AI 看匹配程度、准备招呼语。

适合自己筛岗、对比和准备沟通。它不替你投递，也不会把消息发出去。

目前是同学之间的小范围体验，还不是面向所有人的正式版。

---

## 安装

用 Chrome 或 Edge。从 [发布页](https://github.com/DikkooXie/job-filter-assistant/releases) 下载 zip，以「加载已解压的扩展程序」安装。

这次体验请下**预发布**包，不要只点页面上的 Latest。Latest 仍是正式版（目前是 v1.0.3）。预发布的版本号是四段，例如 **1.0.3.12**，标题旁有 Pre-release。安装包文件名类似 `job-filter-assistant-1.0.3.12.zip`。

1. 在发布页打开四段版本那一条，下载 zip。
2. 解压到一个固定文件夹，例如 `文档/扩展/Offercome`。文件夹里应能直接看到 `manifest.json`。不要放在「下载」或「桌面」的根目录，否则之后在扩展里更新时，浏览器可能不让你授权这个位置。
3. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`，打开「开发人员模式」。
4. 选「加载已解压的扩展程序」，选中刚才的文件夹。
5. 把 **Offercome** 固定到工具栏。点图标，再点「打开岗位面板」。设置从弹窗里的「画像与设置」进入，或从岗位面板右上角的齿轮进入。

安装时浏览器可能提示可以读取所有网站上的数据。这是为了把请求发到你自己填写的模型地址（各家域名不一样）。岗位只在 BOSS直聘和前程无忧上收录。

**解压出来的文件夹就是扩展本身。** 浏览器不会另外复制一份。请一直放在原处，不要删除、移动或改名，否则扩展会打不开。忘了放在哪：扩展管理页里本扩展的「来源」就是位置。

画像、岗位、模型密钥和设置保存在浏览器里，不在这个文件夹里。文件夹若被删掉：把 zip 重新解压回「来源」显示的同一位置，再点「重新加载」。不要点「移除」——移除会清掉浏览器里的这些数据。

## 更新与预览通道

打开 **设置 → 通用与隐私**，页底是 **关于与更新**。

| 通道 | 会安装什么 |
|---|---|
| **稳定**（默认） | 只看正式版，也就是发布页上的 Latest（[/releases/latest](https://github.com/DikkooXie/job-filter-assistant/releases/latest)）。四段预发布不会出现在这里。 |
| **预览** | 才会检查并安装预发布。版本号是四段，例如 `1.0.3.12`，且必须高于当前已装版本。 |

这次小范围体验：装好后把通道选成 **预览**，再点「检查更新」。Latest 始终是正式版，选预览不会把 Latest 改成预发布。

已经装着比正式版更新的预览时，切回「稳定」**不会自动降级**。若正式版并不比当前新，面板会提示你到正式版发布页下载 zip，覆盖原来的文件夹，再在扩展管理页点「重新加载」。

扩展内更新：

1. 点「检查更新」。有更高版本时点「更新到 …」。
2. 第一次会弹出文件夹选择。选扩展管理页「来源」那个文件夹，并允许编辑。之后会记住，一般不用再选。
3. 扩展下载安装包、校验后覆盖文件并重新加载，设置页会再打开。岗位、画像和模型配置都还在。

自动更新失败时，按面板里的手动步骤：下载对应 zip → 解压覆盖到原文件夹 → 扩展管理页点「重新加载」。

## 第一次使用

1. **设置 → 模型接口**：选一个供应商，填上你自己的 API Key 和模型。
2. **设置 → 个人画像**：上传简历（PDF / DOCX / TXT）让 AI 抽取，看过再保存；也可以直接手填。
3. 打开 **BOSS直聘** 或 **前程无忧** 的岗位列表，正常往下翻。岗位会出现在侧边栏的「岗位库」里，点「AI 分析」看匹配。

---

## 能做什么

- **两个平台一起记。** BOSS直聘和前程无忧用同一个扩展。可以跟随你当前打开的网站，也可以只看其中一个。
- **浏览时顺便收录。** 你自己翻列表或点开详情时，页面里已经加载的岗位会进岗位库，不用逐条复制。
- **个人画像。** 用简历抽取或手填。有完整度提示，也可以一键清除。
- **AI 匹配。** 按画像给岗位打分，并写出契合点、差距和风险。经验年限、学历等写明了的硬性要求对不上时，会单独提示。也可以看到技能、经验、岗位要求和城市这几方面的分数。可以单个分析，也可以勾选后批量分析。结果存在本机，画像或模型变了才重算。
- **批量导出。** 把勾选的岗位导出成表格，Excel / WPS 可以直接打开。
- **招呼语。** 一次生成精简、标准、详细三档，可以改、可以复制。也可以打开岗位页并把文字复制好，你核对招聘方之后自己粘贴、自己发送。
- **简历建议。** 按这个岗位的描述，建议简历里可以突出什么、缺什么。只给建议，不编造经历，也不改你的简历文件。
- **本地筛选。** 关键词、风险词、城市、薪资、经验、学历、屏蔽公司。在你电脑上过滤，不调用 AI，不花接口额度。
- **模型自己配。** 不绑定一家。设置里可以一键添加 OpenAI、DeepSeek、通义千问、智谱、Kimi、硅基流动、Claude、Gemini，以及本机的 Ollama。列表里没有的，只要接口和上述某一家兼容，填上地址即可。

## 使用前请知道

- **不会自动发消息。** 招呼语只生成和复制。发到 BOSS 或前程无忧，要你自己粘贴、自己点发送。「标记已发送」只在本机记一笔，不会真的发出去。
- **网站一改版，收录可能失灵。** 列表结构变了，岗位可能收不进来，或只剩标题。描述是空的时候，匹配缺少依据；打开原岗位详情后，有时能把描述补上，补不上就先跳过或自己看。
- **要自备 API Key。** 分析、抽画像、写招呼语都走你填写的接口，费用记在你的账户上。没有 Key 就只能收录和做本地筛选。
- **数据在本机，调用 AI 时会发出去。** 密钥、画像和岗位库都在这台浏览器里，不会另外上传到 Offercome 的服务器。你点了分析或抽取之后，相关内容会发到你配置的模型服务。默认会尽量隐去手机号、邮箱、联系方式和常见个人主页链接，但不能保证去掉所有个人信息。公司名默认会发给模型，可在「通用与隐私」里关掉。
- **只供个人求职时辅助看看。** 请遵守各平台的规则，不要拿它高频、大批量地抓岗位。
